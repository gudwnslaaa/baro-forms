견적서 작성법: 꼭 들어가야 할 항목과 자주 하는 실수

바로서식 작성 가이드 · 2026.11.10 작성

견적서는 일을 맡기 전에 "이 작업을 이 금액에 해 드리겠습니다"라고 제안하는 문서입니다. 법으로 정해진 양식은 없지만, 받는 사람이 금액과 조건을 한눈에 비교할 수 있어야 계약으로 이어집니다. 이 글에서는 견적서에 들어가야 할 항목과 작성 순서를 정리합니다.

견적서에 꼭 들어가야 할 항목

항목설명
문서번호 · 견적일자나중에 "어느 견적서 기준이냐"를 확인할 때 씁니다. 같은 거래처에 여러 번 보낼수록 중요합니다.
받는 곳거래처 상호와 담당자 이름. 개인 고객이면 이름만 적어도 됩니다.
공급자 정보사업자등록번호, 상호, 대표자, 주소, 업태·종목, 연락처. 거래처가 사업자 확인을 할 때 필요합니다.
품목 내역품명, 규격, 수량, 단가, 공급가액, 세액. 한 줄에 한 가지씩 나눠 적어야 비교가 쉽습니다.
합계금액숫자와 한글을 함께 적습니다(예: 일금 일백만원정, ₩1,000,000). 위·변조를 막고 오해를 줄입니다.
부가세 표시합계가 부가세 포함인지 별도인지 반드시 밝힙니다.
유효기간이 금액을 언제까지 보장하는지. 자재값이 자주 바뀌는 업종일수록 짧게 잡습니다.
비고결제 조건, 착수·완료 일정, 포함되지 않는 작업, 추가 비용이 생기는 경우 등.

작성 순서

  1. 요청 내용 확인 — 거래처가 원하는 범위와 수량, 납기를 먼저 정리합니다. 범위가 애매하면 견적 전에 질문해 두는 것이 좋습니다.
  2. 품목 나누기 — "인테리어 공사 일식"처럼 뭉뚱그리기보다 자재, 시공, 운반, 폐기물 처리처럼 나눠 적습니다. 나중에 일부만 변경할 때도 계산이 쉬워집니다.
  3. 단가와 수량 입력 — 단위(개, m², 식, 시간)를 규격 칸이나 품명에 함께 적습니다.
  4. 부가세 방식 선택 — 사업자끼리의 거래는 보통 부가세 별도로 적고, 개인 고객에게는 부가세를 포함한 최종 금액을 보여 주는 편이 오해가 적습니다.
  5. 조건 적기 — 유효기간, 결제 조건(계약금·잔금 비율), 견적에 포함되지 않는 항목을 비고에 적습니다.
  6. PDF로 보내기 — 인쇄 창에서 PDF로 저장하면 받는 쪽에서 내용이 바뀌지 않고, 휴대폰에서도 그대로 열립니다.

자주 하는 실수

  • 부가세 표시 누락 — 100만 원이라고만 적으면 받는 쪽은 110만 원인지 100만 원인지 알 수 없습니다. 가장 흔한 분쟁 원인입니다.
  • 유효기간 없음 — 몇 달 뒤 "그때 그 금액으로 해 달라"는 요청을 받을 수 있습니다.
  • 포함·불포함 범위가 불분명 — 운반비, 설치비, 폐기물 처리비처럼 따로 드는 비용은 포함 여부를 꼭 적습니다.
  • 합계 계산 오류 — 손으로 계산하면 품목 합계와 총액이 어긋나기 쉽습니다. 자동 계산되는 양식을 쓰면 줄일 수 있습니다.

견적서는 계약서인가요?

견적서 자체는 계약을 제안하는 문서이고, 상대방이 받아들여야 거래 조건으로 확정됩니다. 금액이 크거나 일정·하자 보수 조건이 중요한 거래라면 견적서를 바탕으로 계약서를 따로 작성하는 것이 안전합니다.

위 항목이 모두 들어간 양식을 바로 쓰려면 견적서 무료 작성기를 이용하세요. 품목만 입력하면 공급가액·부가세·한글 금액이 자동으로 계산됩니다.
