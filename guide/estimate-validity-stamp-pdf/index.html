견적서 유효기간, 직인, PDF 저장까지 실무 정리

바로서식 작성 가이드 · 2026.11.10 작성

견적서 내용을 다 채웠다면 마지막으로 챙길 것이 유효기간, 직인, 보내는 형식입니다. 작은 부분이지만 거래처가 받았을 때 신뢰도를 크게 좌우합니다.

유효기간은 며칠이 적당할까?

유효기간은 "이 금액을 언제까지 보장하는가"를 뜻합니다. 정해진 기준은 없고 업종마다 다르게 씁니다.

기간어울리는 경우
7일자재·원자재 가격이 자주 바뀌는 업종, 재고가 한정된 물품
15일일반적인 납품, 소규모 공사
30일가격 변동이 적은 서비스, 결재 과정이 긴 기업·기관 거래

유효기간이 지난 뒤 다시 주문이 오면 금액을 다시 확인하고 새 견적서를 보내면 됩니다. 비고에 "유효기간 이후에는 단가가 변동될 수 있습니다"라고 적어 두면 더 분명합니다.

직인은 꼭 찍어야 할까?

견적서에 직인을 찍는 것은 법적 의무가 아니라 관행입니다. 다만 기업이나 공공기관은 내부 결재 때문에 직인이 찍힌 견적서를 요구하는 경우가 많습니다. 미리 직인 이미지를 준비해 두면 매번 출력해서 도장을 찍고 스캔하는 수고를 덜 수 있습니다.

직인 이미지를 만드는 방법

  1. 흰 종이에 도장을 선명하게 찍습니다.
  2. 휴대폰으로 그림자가 지지 않게 정면에서 촬영하거나 스캔합니다.
  3. 사진 편집 앱이나 무료 배경 제거 도구로 흰 배경을 지우고 PNG로 저장합니다. JPG는 투명 배경을 지원하지 않아 네모난 흰 바탕이 남습니다.
  4. 도장 부분만 남도록 여백을 잘라 정사각형에 가깝게 만듭니다.

배경을 지우지 못했더라도 바로서식 작성기는 직인을 글자 위에 겹칠 때 흰 부분이 비치도록 처리해서 대부분 자연스럽게 보입니다.

PDF로 저장해서 보내기

  1. 작성기에서 인쇄 · PDF 저장 버튼을 누릅니다.
  2. 인쇄 창의 대상(프린터)을 PDF로 저장 또는 Microsoft Print to PDF로 바꿉니다.
  3. 용지는 A4, 여백은 없음, 배율은 기본값(100%)으로 두면 화면과 같은 모양으로 저장됩니다.
  4. 파일 이름은 "견적서_거래처_날짜" 형태로 자동 제안됩니다.

PDF는 받는 사람이 내용을 쉽게 고칠 수 없고, 컴퓨터와 휴대폰 어디서나 모양이 똑같이 보여서 견적서를 보내기에 가장 무난한 형식입니다.
